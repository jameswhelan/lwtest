# Typography

Use the Typography component or Tailwind font classes.

## Typography Component

```tsx
import { Typography } from "./components";

<Typography variant="h1">Heading 1</Typography>
<Typography variant="body">Body text</Typography>
<Typography variant="caption" color="muted">Caption</Typography>
```

## Variants

- h1, h2, h3, h4 — Headings
- body-lg, body, body-sm — Body text
- caption — Small secondary text
- label — Form labels

## Tailwind Classes

- `text-lw-xs`, `text-lw-sm`, `text-lw-base`, `text-lw-lg`, `text-lw-xl`, `text-lw-2xl`, `text-lw-3xl`
- `font-medium`, `font-semibold`, `font-bold`

Sync exact values from Figma design specs.
